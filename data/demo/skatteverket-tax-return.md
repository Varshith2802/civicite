# Filing the annual income tax return (inkomstdeklaration)

## Who files
Individuals who had taxable income in Sweden during the previous calendar year normally receive an
income tax return from Skatteverket in the spring, pre-filled with information from employers, banks
and authorities.

## Deadline
The income tax return must be submitted no later than 2 May. If 2 May falls on a Saturday, Sunday or
public holiday, the deadline moves to the next working day. If you need more time, you can apply for
a deferral (anstånd) before the deadline.

## How to file
You check the pre-filled information, correct or add what is missing, and approve the return. This can
be done in Skatteverket's e-service or app with an e-identification, or on paper.

## Late filing
If you file late, Skatteverket can charge a late filing fee (förseningsavgift).
